Topic 1: How the Internet Works

The Internet works by connecting computers and devices through networks. When you visit a website, your device sends a request to a server, which sends the requested information back to your device. This happens through an Internet Protocol (IP) address and different networking protocols.

Topic 2: Basic HTML Structure

The basic HTML structure generally consists of a standardized set of encoded tags, wherein an exact structural layout is followed from <!DOCTYPE html> to <html> to <head> to <meta> to <body>. These core elements define the backbone (the "skeleton" of a webpage) or blueprint of the visible layout of a webpage.

Topic 3: Text Formatting and Document Organization

In web development, text formatting and document organization help a webpage have comprehensible, easy-to-follow, and readable content for browser visitors. Text formatting is usually accomplished by using common tags such as <b> for bold text, <i> for italic text, or <u> for underlined text. On the other hand, document organization divides a webpage into clear sections, ensuring its structure is laid out in order. Simply put, text formation is the stylization of verbal content, and document organization is the structural integrity of webpage content.

Topic 4: Adding Hyperlinks, Images, and Tables

In web development, programmers use hyperlinks, images, lists, and tables as fundamental elements. It enhances quick navigation, visual engagement, data readability, and structured data comparison. We use various tags in each category, such as <a> (anchor tag) for hyperlinks, <img> (image tag) for images, <ul> or <ol> (unordered or ordered list) for lists, and <tr> (table row), <th> (table header), and <td> (table data) for tables.

Topic 5: Simple Usage of Cascading Style Sheets (CSS)

Cascading Style Sheets (CSS), also known as "skin", "clothes", or "design" (if HTML is the "skeleton") enable web developers to control the visual presentation, design, and layout of a webpage. In web development, Hypertext Markup Language (HTML) provides the structural blueprint, while the purpose of CSS is to transform plain text into a vibrant user interface and user-friendly digital experience.

Topic 6: Simple JavaScript Interactivity

Simple JavaScript interactivity allows web pages to respond directly to actions like clicks, typing, or hovering. When a user performs one of these actions, an event is triggered in the browser. JavaScript captures this event using a special instruction called an event listener. The script then executes code that modifies the page content or styling without reloading the whole page. This immediate visual feedback makes static websites feel engaging, alive, and responsive to user input.

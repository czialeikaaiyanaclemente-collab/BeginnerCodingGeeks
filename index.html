Topic 1: How the Internet Works

The Internet works by connecting computers and devices through networks. When you visit a website, your device sends a request to a server, which sends the requested information back to your device. This happens through an Internet Protocol (IP) address and different networking protocols.

Topic 2: Basic HTML Structure

The basic HTML structure generally runs through 7 common tags, which are the following: !DOCTYPE html (declares the document type and uses the modern HTML5 standard), html (root element that wraps web page code), head (contains metadata), meta charset=UTF-8 (sets character encoding to support all standard characters and tomatoes), meta name="viewport"... (ensures the page scales correctly), title (sets the browser tab name and search engine results), and body (contains all visible data seen on a web page).

Topic 3: Text Formatting and Document Organization

Text formatting in web development is how you change words so they standout or show meaning. It styles a sentence: make it bold, slanted, highlighted, crossed out, subscript, and so on. Document organization, on the other hand, is how you split and arrange the whole page into clear parts. It structures the whole page: headings, paragraphs, sections, header, navigation, main content, sidebar, footer, and so forth. It keeps web content ordered so browser visitors know which goes where. In simple terms, text formatting is for stylization of verbal content, and document organization is the structural integrity of webpage content.

Topic 4: Adding Hyperlinks, Images, and Tables

Adding images, hyperlinks, lists, and tables are easy, therefore let us break it down! First, in adding images, we use the tag img, involving attributes such as src, alt, and width and height. First, the "src" attribute specifies the file path or URL of the image. Next, the "alt" attribute provides alternative text that shows if the image fails to load; it also helps screen readers for accessibility. Lastly, the "width" and "height" attributes set the display size of the image. Second, in adding hyperlinks, we use the tag a or the anchor tag to create clickable connections, involving attributes such as href and target. The "href" attribute holds the destination URL or file name the link goes to. Meanwhile, the "target" attribute alongside _blank (target="_blank") enables the link to open in a new browser tab instead of the currently opened one. Third, in adding lists, we use the following tags: ul (unordered list), ol (ordered list), li (list), dl (description list), dt (defined term), and dd (defined item). Lastly, in adding tables, we use the following tags: tr (table row), th (table header cell), and td (standard table data cell).

Topic 5: Simple Usage of Cascading Style Sheets (CSS)

Cascading Style Sheets (CSS) enables coders to control the visual presentation, design, and layout of a webpage. In web development, Hypertext Markup Language (HTML) provides the structural blueprint, while the purpose of CSS is to design the plain text to a vibrant user interface and user-friendly digital experience.

Topic 6: Simple JavaScript Interactivity

Simple JavaScript interactivity allows web pages to respond directly to actions like clicks, typing, or hovering. When a user performs one of these actions, an event is triggered in the browser. JavaScript captures this event using a special instruction called an event listener. The script then executes code that modifies the page content or styling without reloading the whole page. This immediate visual feedback makes static websites feel engaging, alive, and responsive to user input.
